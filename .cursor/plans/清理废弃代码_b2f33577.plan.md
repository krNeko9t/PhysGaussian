# 按计划清理仓库废弃代码

## 背景（与计划对齐）

[`.cursor/plans/pipeline配置重设计_4059f61c.plan.md`](.cursor/plans/pipeline配置重设计_4059f61c.plan.md) 中「删除/废弃」与「cleanup todo」写明：

- `experiments/*.yaml` — 迁移为 `.py` 后删除  
- `warp_mpm` — 从 pipeline 与 backend 分发中移除（当前 [`physics_sim/backend/registry.py`](physics_sim/backend/registry.py) 仅支持 `newton_rigid` / `newton_vbd` / `newton_mpm` / `none`，已无 `warp_mpm`）  
- 旧 `schema.py`、旧 `conf/` — 仓库中已不存在，无需操作  

你已确认：**保留** [`phys_desc_to_config.py`](phys_desc_to_config.py)、[`physics_sim/config/material_lut.json`](physics_sim/config/material_lut.json)、[`physics_sim/config/geometry_lut.json`](physics_sim/config/geometry_lut.json) 以及整个 [`examples/`](examples/) 目录。

## 将执行的具体变更

### 1. 删除已迁移的实验 YAML（4 个文件）

与同名 `.py` 重复、且主线入口 [`pipeline.py`](pipeline.py) 仅加载 Python 配置：

- [`experiments/wolf_bread_rigid.yaml`](experiments/wolf_bread_rigid.yaml)  
- [`experiments/wolf_bread_vbd.yaml`](experiments/wolf_bread_vbd.yaml)  
- [`experiments/wolf_sand.yaml`](experiments/wolf_sand.yaml)（内含已废弃的 `warp_mpm` 引用，删除可避免误导）  
- [`experiments/bench_auto_vbd.yaml`](experiments/bench_auto_vbd.yaml)  

### 2. 删除 `physics_sim/backend/warp_mpm/` 整包

该目录实现 `WarpMPMBackend`，但全仓库无其它 Python 文件 `import` 该包（仅包内自引用与注释）。删除后可减少维护面与 `warp_lang` 相关死代码路径。

**注意**：删除后若本地仍依赖 Warp MPM，应改用 `newton_mpm`（见 [`experiments/wolf_sand.py`](experiments/wolf_sand.py) 注释中的迁移说明）。

### 3. 删除 [`physics_sim/config/parser.py`](physics_sim/config/parser.py)

- 模块标注为 **LEGACY**，`decode_param_json` **未被** 仓库内任何其它 `.py` 引用（`rg` 仅命中定义处）。  
- [`physics_sim/config/__init__.py`](physics_sim/config/__init__.py) 未导出该模块。  

删除不会影响当前 `load_config` + `SimConfig` 主路径。

### 4. 小改 [`phys_desc_to_config.py`](phys_desc_to_config.py)

- 将 `--backend-preference` 的 `choices` 中的 `"warp_mpm"` 去掉，与已删除后端一致，避免 CLI 仍宣称支持已移除实现。

（保留脚本与两个 LUT；若日后要让转换器对接当前管线，需另开任务：输出 `SimConfig` / `.py`，而非本次范围。）

- `schema.py` / `physics_sim/conf/` 已不存在，无需删除。
