所有 7 个任务已全部完成。下面是改动摘要：

---

### 第 1 层：PLY 加载 — 自动检测格式
**`physics_sim/renderer/gs_renderer.py`** `load_ply()`
- 通过 `scale_*` 属性数量自动检测：2 个 → 2DGS，3 个 → 3DGS
- 2DGS 时，第三个 scale 用 `log(1e-7)` 填充，使 `build_covariance` 仍可产出有效的薄碟协方差
- 返回新增字段：`gs_type`、`quats` (N,4 wxyz)、`scales` (N,2|3 exp 后的原始 scale)

### 第 2 层：SimulationState 扩展
**`physics_sim/backend/base.py`**
- 新增 `quats: Optional[torch.Tensor]` 和 `scales: Optional[torch.Tensor]`，默认 `None`
- 3DGS 场景完全不受影响

### 第 3 层：物理后端输出 quats+scales

**刚体后端 (newton_rigid, newton_vbd)** — 零额外开销
- `_BodyInfo` / `_RigidInfo` 新增 `init_quats`、`init_scales`
- `initialize()` 从 kwargs 获取并存储 `init_quats`、`init_scales`
- `get_state()` 通过 Hamilton 乘积组合 body 四元数和粒子初始四元数，scales 直接透传
- 新增 `_compose_body_quat_wxyz()` 辅助函数处理 Newton xyzw ↔ 3DGS wxyz 转换

**MPM 后端 (newton_mpm, warp_mpm)** — 复用已有 SVD
- **`physics_sim/backend/newton_mpm/kernels.py`**: 新增 Warp 函数 `_rotmat_to_quat_wxyz`、`_quat_mul_wxyz` 和内核 `compute_R_quats_scales_from_F`
  - 同一次 SVD 输出 R (用于 SH)、quaternion (`R_deform * q_init`)、scales (`sig * init_scales`)
- `newton_mpm/solver.py` 和 `warp_mpm/solver.py`: 在 `get_state()` 中根据是否有 init_quats 选择调用新/旧内核
- warp_mpm 直接复用 newton_mpm 的独立内核，以 `mpm_state.particle_F_trial` 作为 F 输入

### 第 4 层：渲染接口扩展
**`backend_base.py`**: `RasterBackend.render()` 签名变为 keyword-only 参数 `cov6` / `quats` / `scales`

**`backend_gsplat.py`**: 
- `render()` 根据参数自动派发到 `_render_3dgs()` (covars 模式) 或 `_render_2dgs()` (`rasterization_2dgs`)

**`backend_diffrast.py`**: 适配新签名，收到 `quats+scales` 时报错（不支持原生 2DGS）

**`gs_renderer.py`**: `GaussianRenderer.render()` 透传新参数

### 第 5 层：Pipeline 串联
**`pipeline.py`**:
- 加载 PLY 后记录 `gs_type`、`init_ply_quats`、`init_ply_scales`
- 新增辅助函数：`preprocess_quats()`、`inverse_preprocess_quats()`、`_rotmat_to_quat_wxyz()`、`_quat_mul_wxyz()`、`_build_axis_perm_matrix()` 处理坐标变换
- 初始化 backend 前，对 quats 应用预处理旋转链（axis_perm + rotation_matrices），scales 无需 scale_origin 预处理（round-trip 中自然抵消）
- 帧循环中：2DGS 从 `state.quats/scales` 获取并做反向旋转变换后传给 `renderer.render(quats=..., scales=...)`；3DGS 仍走 `cov6` 路径
- 多物体和单物体两条路径均已适配 quats/scales 的过滤和拼接
- `_NoPhysicsBackend` (render-only) 也正确透传 quats/scales
